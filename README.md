# Tulos

The score keeper for game night. Every player gets a bold colored card, and
the whole card is the button — tap anywhere to add a point, swipe down to
take one away, hold for a custom amount. Two to eight players, rounds for
card games, and a live scoreboard on your lock screen.

Pay once. No ads. No account. Just play.

**App Store:** coming soon
**Website & support:** https://dresende.github.io/tulos/
**Privacy policy:** https://dresende.github.io/tulos/privacy.html

This repository hosts Tulos's public website (GitHub Pages). It is plain
hand-written HTML with no build step and no dependencies.

The app screens on the landing page are drawn in CSS rather than embedded as
screenshots — it keeps the whole page under 40 KB and crisp at any density.
They mirror `Theme.swift` and the string catalog in the (private) app repo, so
if the player colors or in-app wording change, update `index.html` to match.
